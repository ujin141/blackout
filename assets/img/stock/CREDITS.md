# 외부 이미지 출처

여기 있는 파일은 **전부 저작권이 완전히 자유로운 것만** 씁니다.
새 이미지를 추가하면 반드시 이 표에 출처와 라이선스를 적으세요.

| 파일 | 출처 | 라이선스 | 표기 의무 | 상업적 사용 |
|---|---|---|---|---|
| `pool-cc0.jpg` | [Wikimedia Commons — A close up of a swimming pool with water](https://commons.wikimedia.org/wiki/File:A_close_up_of_a_swimming_pool_with_water_by_Markus_Spiske_(Unsplash).jpg) (Markus Spiske / Unsplash) | **CC0** (저작권 포기) | 없음 | 가능 |

## 고를 때 기준

- **CC0 · Public Domain 만** 씁니다. CC BY 는 포스터에 출처를 박아야 해서 쓰지 않습니다.
- 사람 얼굴이 크게 나오는 사진은 피합니다. 저작권과 별개로 **초상권** 문제가 남습니다.
- Wikimedia Commons API 로 라이선스를 확인하고 받습니다 (`LicenseShortName` 이 CC0 인지).
