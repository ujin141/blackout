# 캡션

## 먼저 읽을 것

1. `video/event.py` — 날짜·값·정원·차수. **숫자를 여기서만 가져온다.**
   기억으로 쓰지 말 것. 값이 바뀌면 캡션이 조용히 틀린다
2. `mail/인스타광고_운영.md` — 이미 쓴 캡션들. **첫 줄과 해시태그가 겹치면 안 된다**
3. `CLAUDE.md` 의 말투 규칙

## 판마다 길이가 다르다

| 판 | 길이 | 첫 줄이 하는 일 |
|---|---|---|
| 릴스·피드 | 8~12줄 | 접히기 전 두 줄에 무슨 행사인지 |
| 스토리 | 없음 | 링크 스티커만. 영상이 다 말한다 |
| 오픈챗 | **네 줄** | 길면 읽는 게 아니라 지나간다 |
| 광고 기본 문구 | 4~5줄 | 게시물 캡션보다 더 빨리 접힌다 |

## 첫 줄이 전부다

**세 릴스가 각자 다른 각으로 시작한다.** 새 캡션도 이 셋과 달라야 한다.

```
short_ad     혼자 와도 된다      문턱을 지운다
short_promo  스토리 한 번이면    품이 안 든다
short_sale   1차는 풀만석        늦으면 못 간다
```

남은 각: **왜 우리가 이걸 여는지** · **끝나고 뭐 하는지(애프터)** ·
**혼자 온 사람이 실제로 어떻게 되는지**

## 쓰지 않는 것

- **성비** — 당일 보장이 아니고 캡처가 남는다
- **"마지막 기회" · "곧 마감"** — 3차가 남아 있는 동안은 거짓이다.
  이 말은 3차가 열린 뒤 **딱 한 번만** 쓴다
- **샴페인 브랜드** — 라벨(`DEEP`)과 부르는 이름('디바')이 아직 안 맞는다
- **"~하실 수 있습니다" · "함께 만들어가요" · "여러분의"**
- **이모지 남발** · **세 개씩 늘어놓는 병렬 구조**
- **해시태그 여섯 개 이상** — 다섯이 상한. 오픈챗에서는 아예 안 쓴다

## 항상 붙이는 것

- **첫 댓글 한 줄.** 캡션을 안 늘리고 링크·조건을 한 번 더 준다
- **CTA 는 하나.** 두 개를 주면 둘 다 안 누른다

## 끝나면

`mail/` 의 해당 문서에 넣는다. **두 군데에 같은 캡션을 두지 않는다** —
한쪽만 고치게 된다.
