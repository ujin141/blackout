# 영상 점검

**프레임을 뽑아서 본다.** 코드만 읽고 판단하지 않는다.

```bash
ffprobe -v error -show_entries stream=codec_type,width,height,duration -of default=nw=1 <파일>
for t in 0.5 2.4 4.3 6.2 8.1 10.0; do
  ffmpeg -v error -y -ss $t -i <파일> -frames:v 1 f_$t.png
done
```

여러 장을 한 판에 붙여서 본다. **한 장씩 보면 "같은 그림이 두 번 나온다" 를
못 잡는다.**

## 반드시 확인

- [ ] **가로세로 1080×1920**, 15초 안쪽
- [ ] **소리 트랙이 있는가** — `ffprobe` 에 `codec_type=audio` 가 보여야 한다.
      `audio_*.py` 를 먼저 안 돌리면 조용히 무음으로 나온다
- [ ] 영상 길이 == 곡 길이. **컷이 곡보다 길면 `-shortest` 가 뒤를 잘라서
      끝 카드가 통째로 사라진다.** 실제로 그렇게 잘린 적이 있다
- [ ] 첫 1초에 **사람이나 움직임**. 로고·타이틀로 시작하면 넘긴다
- [ ] **음소거로 봐도 말이 전달되는가.** 자막 없으면 아무 말도 안 한다

## 컷

- **같은 구간을 두 번 쓰지 않는다.** 시작초가 겹치면 같은 그림이 또 나온다 —
  눈으로는 잘 안 잡히니 assert 로 막는다
- **구간이 안 겹쳐도 구도가 닮으면 붙여 놓지 않는다.** 다른 클립인데 같은
  커튼·수영장 모서리가 잡혀서 두 컷이 한 컷처럼 보인 적이 있다
- **컷이 클립 끝을 넘으면 검은 프레임이 나온다.** 시작점을 클립 안으로 민다
- **정지 사진·정지 크롭에는 느린 푸시인을 넣는다.** 안 넣으면 손 흔들림만
  보여서 컷이 애매해진다. 6% 안쪽이면 화질은 안 깨진다

## 자막과 안전영역

| | 덮이는 곳 |
|---|---|
| 릴스 | 아래 **25%** · 위 **14%** |
| 스토리 | 아래에서 답장 막대가 올라온다 — 자막을 더 위로 |

- **글자 뒤에 검은 띠를 두르지 않는다.** 얹은 물건으로 읽힌다 —
  화면 아래를 통째로 떨어뜨린다(릴스에서 흔한 색보정이라 분위기로 읽힌다)
- **한 줄을 2초 넘게 붙여 두면 루즈하다.** 두세 박으로 끊고 문장을 쪼갠다
- **강조색은 판 색을 보고 정한다. 글자색이 아니다** —
  산호 판에 산호 강조색을 얹어 줄이 통째로 사라진 적이 있다

## 손님 얼굴

- 게시물은 팔로워가 보지만 **광고는 모르는 사람 수만 명에게 나가고
  캡처가 남는다** — 정면 얼굴이 가운데 오는 컷은 광고용 목록에서 뺀다
- 어느 컷을 골라도 얼굴이 나오면 흐림을 넣는다.
  **장면은 읽히되 개인은 안 잡히는 선까지만**

## 사실 확인

**`event.py` 의 오늘 상태와 영상 속 문장이 맞는가.**
차수가 열렸는데 `SALE` 을 안 고치면 판에 옛말이 남는다 — 실제로
`남은 건 테이블뿐` 이 `30자리 남았습니다` 와 같은 영상 안에서 부딪혔다.

**같은 말을 두 칸에서 하지 않는다.**

## 다시 뽑아야 하는 것

문구나 `event.py` 를 고쳤으면 **그 문장을 쓰는 영상을 전부** 다시 뽑는다.
하나만 고치면 판마다 말이 달라진다.

```bash
cd video && python short_card.py sale ad promo
```
