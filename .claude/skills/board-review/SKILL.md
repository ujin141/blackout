# 판 점검

**반드시 이미지를 열어서 본다.** 코드만 읽고 판단하지 않는다 —
이 저장소에서 난 문제는 대부분 코드가 맞는데 눈으로 보면 틀린 것들이었다.

영상이면 프레임을 뽑아 붙여서 본다.

```bash
ffmpeg -v error -y -ss <초> -i <파일> -frames:v 1 out.png
```

## 잡아야 할 것 — 실제로 났던 순서대로

### 1. 색이 색을 먹는다

**강조색을 글자색 기준으로 고르면 안 된다. 판 색을 봐야 한다.**
산호 판에 산호 강조색을 얹어서 `2차 OPEN` 줄이 통째로 사라진 적이 있다.
청록 판 위의 산호처럼 **밝은 색끼리 겹치면 둘 다 죽는다.**

### 2. 같은 말을 두 번 한다

- 훅이 `1차 사전예약 풀만석` 인데 상태줄도 `1차 사전예약 SOLD OUT`
- 카드 1이 `1차 사전예약 풀만석`, 카드 2가 `1차 20명 마감`
- 커버에 아이디가 크게 있는데 발치에 서명이 또

**한 판에서 같은 말은 한 번.** 격자에서는 **두 칸이 같은 말을 하면
한 칸을 버리는 것**이다.

### 3. 옛 상태가 남는다

`event.py` 의 `SALE`·`WAVES` 가 오늘과 다르면 판에 옛말이 찍힌다 —
실제로 2차가 열린 뒤에도 `남은 건 테이블뿐` 이 영상에 남아 있었고,
같은 영상의 `30자리 남았습니다` 와 정면으로 부딪혔다.

**판에 나온 문장이 오늘 사실인지 확인한다.**

### 4. 손님 얼굴

- 영상은 지나가지만 **커버는 프로필에 계속 남는다** — 기준이 더 높다
- **광고는 도달이 넓고 캡처가 남는다** — 정면 얼굴이 가운데 오는 컷은 뺀다
- 어느 컷을 골라도 얼굴이 나오면 **흐림을 넣는다**(장면은 읽히되 개인은 안 잡히는 선).
  `assets/img/event/bg.webp` · `short_cover.py` 의 `soft` 가 그 예다

### 5. 잘리는 선

| 판 | 살아 있는 구간 |
|---|---|
| 릴스 커버 | **가운데 1080×1350**(위아래 285px 잘림) |
| 스토리 | 위 14% · 아래 25% 를 UI 가 덮는다 |
| 릴스 재생 | 아래 25% 에 자막·버튼이 앉는다 |
| 인쇄물 | 재단선 안쪽 |

**눈으로는 못 본다 — 자리를 재서 assert 로 막는다.**

### 6. 여백

우진님이 제일 자주 지적하는 것이다. **판이 반만 차 있으면 다시 짠다.**
글자를 키우거나 정보를 넣는다. 여백을 늘리는 방향은 대부분 틀렸다.

### 7. 글자 뒤

**검은 테두리·그림자·띠를 두르지 않는다.** 얹은 물건으로 읽힌다.
대신 배경을 통째로 떨어뜨린다(그라데이션). 다만 **사람이 아래쪽에 몰린
사진은 세게 누르면 "많다" 가 어둠 속으로 사라진다** — 누르는 정도를 판마다 준다.

## 보고할 때

**고칠 것만 짧게.** 잘된 점 나열하지 않는다.
고칠 게 없으면 "없습니다" 한 줄이면 된다.
