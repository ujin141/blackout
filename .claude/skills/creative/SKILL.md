# 소재

## 먼저 — 만들 필요가 있는지 본다

**이 저장소는 자산이 남고 채널이 빈다.** 새로 만들기 전에 `/distribute` 를
보고, 이미 만든 게 안 나갔으면 그걸 먼저 말한다.

## 이미 있는 것

```
short_ad.mp4      값 + 인상 고지        직접 판매  · 광고 A안
short_promo.mp4   무료 + 샴페인         혜택      · 광고 B안
short_sale.mp4    1차 풀만석            희소      · 광고 C안
scene_story.mp4   물과 빛               분위기    · 광고에 쓰지 않는다
story_ad.mp4      현장 영상 + 자막      스토리    · 링크 스티커 자리 비움
ai_reel.mp4       상황극 뼈대           공감      · 클립을 넣어야 완성
```

**새 소재는 이 여섯과 각이 달라야 한다.** 같은 각을 하나 더 만드는 건
예산과 시간을 나눠 갖기만 한다.

아직 안 쓴 각: **왜 이걸 여는지(크루 이야기)** ·
**혼자 온 사람이 실제로 어떻게 되는지** · **끝나고 뭐 하는지(애프터)** ·
**만드는 과정(준비 브이로그)**

## 각을 정하고 나서

**대부분 새 스크립트가 필요 없다.** 기존 것에 변종을 더한다.

| 만들 것 | 어디에 |
|---|---|
| 릴스 색판 세트 | `short_card.py` 에 모드 추가 (`intro`·`sale`·`promo`·`ad`) |
| 릴스 커버 | `short_cover.py` 의 `VARIANTS` 에 한 줄 |
| 스토리 | `story.py` — 자막이 더 위, 아래는 링크 스티커 자리 |
| 포스터 | `poster_kit.py` 를 쓰는 새 파일 |
| 장면 애니메이션 | `scene_motion.py` |

**새 파일을 만들 때만 새로 짠다.** 기존 스크립트를 복사해 고치면
`event.py` 를 고쳐도 그 복사본만 안 따라온다.

## 지켜야 할 것

- **행사 정보는 `video/event.py` 에서만.** 판 안에 값을 다시 적지 않는다
- **문구는 파일 맨 위 상수로.** `crew.py` 의 `WHO`·`ROLES` 처럼 —
  나중에 한 줄 바꾸려고 판을 뒤지게 하지 않는다
- **흑백이 기본.** 컬러 예외는 행사 모객용 판에만
- **로고를 SVG 로 다시 그리지 않는다**
