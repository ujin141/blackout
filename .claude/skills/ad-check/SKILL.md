# 광고 점검

## 계산은 매번 다시 한다

**숫자를 기억으로 쓰지 말 것.** `video/event.py` 에서 읽어 계산한다.

```
한 명이 남기는 우리 몫 = 평균 입장비 × 입장비 정산 비율(우리 5 / 라운지 5)
손익분기 인원          = 하루 광고비 ÷ 우리 몫
1인당 획득비용(CAC)    = 쓴 광고비 ÷ 광고로 온 예약자
```

**CAC 가 '우리 몫' 을 넘으면 멈춘다.** 넘는데 계속 쓰는 건 자리를 사는 게
아니라 손해를 사는 것이다. 목표는 우리 몫의 **절반 이하**.

바·락커는 계산에 넣지 않는다 — **1인당 얼마 쓰는지 확인된 값이 없다.**
확인되면 그때 넣는다.

## 켜기 전 점검

- [ ] **폼에 유입 경로 문항이 있는가** — 없으면 나머지가 다 무의미하다.
      구글폼에는 픽셀이 안 붙어서 이 문항이 유일한 측정 수단이다
- [ ] 소재를 **게시물로 먼저 올렸는가** — 광고에서 "기존 게시물 사용" 을
      골라야 좋아요·댓글이 한 곳에 쌓인다. 새로 만들면 매번 0에서 시작
- [ ] 프로필 링크가 예약 폼으로 걸려 있는가
- [ ] `event.py` 의 `SALE` · `WAVES` 가 오늘 상태와 맞는가 —
      **차수가 열렸는데 안 고치면 판에 "테이블만 남았다" 같은 옛말이 남는다**

## 세팅에서 틀리기 쉬운 것

| | 맞는 것 |
|---|---|
| 구조 | 캠페인 1 · **광고 세트 1** · 광고 3 |
| 세트를 쪼개면 | 같은 사람 놓고 **자기들끼리 입찰 경쟁**한다 |
| 예산 | 캠페인 레벨(어드밴티지 캠페인 예산). 소재별 금액란은 없다 |
| 입찰 | 최저 비용(자동). 비용 상한을 걸면 배달이 막힌다 |
| 목표 | 트래픽 또는 참여. **전환은 쓰지 않는다**(픽셀 없음) |
| 모수 | 하루 5만 기준 **20만~50만**. 넓게 두라는 말은 예산이 클 때 얘기다 |
| 노출 위치 | 수동 · 인스타만. 오디언스 네트워크는 잘못 누른 클릭이 섞인다 |
| 확장 | 상세 타겟팅 확장 ❌ · 어드밴티지+ ❌ |
| 소재 수 | **셋.** 넷 이상이면 초반 표본이 얇아져 메타가 판단을 못 한다 |
| 다이나믹 크리에이티브 | ❌ 완성된 영상을 비교하는 상황과 안 맞는다 |

## 돌리는 중

- **첫 3일은 손대지 않는다.** 매일 만지면 학습이 리셋된다
- 3일차 — 노출이 거의 안 간 소재를 **광고만** 끈다.
  **세트 설정은 건드리지 않는다**(고치면 학습이 처음부터)
- 6일차 — CAC 를 계산해 계속할지 정한다
- 10일차 — 남은 자리가 적으면 광고를 줄이고 다음 차수 인상 고지로 바꾼다

## 광고로 하면 안 되는 것

- 성비 언급 · "마지막 기회"
- **얼굴이 크게 나오는 손님 컷** — 광고는 도달이 넓고 캡처가 남는다
- 노출 위주 이미지 — 심사에서 반려되거나 계정에 제한이 걸린다
- **AI 로 만든 사람 컷** — 심사에서 걸릴 때가 있다.
  오가닉으로 먼저 올려 보고 반응이 좋으면 그 게시물을 홍보하는 쪽이 안전하다

## 마지막에 반드시 말할 것

**광고보다 큰 게 먼저다.** 0원짜리 채널이 아직 안 나갔으면 그것부터.
`/distribute` 참고.
