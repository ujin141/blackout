# 오픈채팅방에 올릴 글

**인스타 캡션을 그대로 붙이지 마세요.** 오픈챗은 다릅니다.

| | 인스타 | 오픈챗 |
|---|---|---|
| 길이 | 접히기 전 두 줄이 승부 | **일곱 줄 넘으면 스크롤로 넘깁니다** |
| 해시태그 | 필요 | **쓰면 광고 티가 납니다** |
| 링크 | 프로필 | **본문에 직접** — 프로필이라는 게 없습니다 |
| 톤 | 판매 | **사람이 말 거는 투** |

---

## ⚠ 올리기 전에

**대부분의 방이 홍보를 금지합니다.** 그냥 올리면 강퇴당하고, 그 방은 영영
못 씁니다 — 60자리 채우자고 채널 하나를 태우는 건 손해입니다.

1. **공지와 방 규칙을 먼저 읽으세요.** '홍보 금지' 가 있으면 안 올립니다
2. 금지가 없어도 **방장에게 먼저 DM** 하세요.
   `파티 하나 여는데 여기 한 번 올려도 될까요?` 한 줄이면 됩니다
3. **한 번만 올립니다.** 반응 없다고 다시 올리면 그게 스팸입니다
4. **들어가자마자 올리지 마세요.** 며칠 대화에 섞인 뒤에 올리는 것과
   가입 5분 만에 링크 던지는 건 받는 쪽에서 완전히 다르게 읽힙니다

## 기본 판 — 홍보가 허용된 방

```
8/29 토요일에 양재 루프탑에서 풀파티 합니다.

해 지기 전엔 물에서 놀고, 9시 반부터 한 시간 반은 솔로파티로 돌립니다.
혼자 오셔도 되는 시간이라 그거 보고 오시는 분들이 많습니다.

어나더 루프탑 라운지 (서초구 양재동 122-6)
저녁 7시부터 자정까지, 끝나고는 강남 ACE에서 이어집니다.

정원 80명인데 1차 사전예약은 풀만석이고 2차 30자리 남았습니다.
여 49,000 남 59,000이고 3차부터 만 원 오릅니다.

예약 https://forms.gle/sue3a9jZNCi8U8dC7
궁금한 거 있으면 여기로 물어보셔도 됩니다.
```

**마지막 줄을 빼지 마세요.** 링크로 끝내면 광고고, 물어보라고 하면 대화입니다.
그리고 실제로 방에서 질문이 붙으면 다른 사람들도 그걸 봅니다 —
그게 글 하나 더 올리는 것보다 셉니다.

## 대화 중에 끼워 넣을 때

**제일 잘 먹히는 방법입니다.** 누가 "주말에 뭐 하지" 류의 말을 했을 때
답으로 다는 겁니다. 이건 홍보가 아니라 대답이라 아무도 뭐라 안 합니다.

```
저희가 29일 토요일에 양재 루프탑에서 풀파티 하는데 오실래요?
9시 반부터는 솔로파티라 혼자 오셔도 됩니다.
https://forms.gle/sue3a9jZNCi8U8dC7
```

**이 타이밍을 노리세요.** 아무 때나 올리는 것보다 훨씬 적게 쓰고 훨씬
많이 옵니다.

**영상은 올리지 마세요** — 오픈챗에서 영상은 데이터 때문에 아무도 안 켭니다.

## 어떤 방에 올릴지

우선순위 순입니다.

1. **크루원들이 이미 들어가 있는 방** — 낯선 사람이 아니라 아는 사람이 올리는 거라 반응이 다릅니다
2. **강남·양재 지역 방**, 클럽·EDM·디제이 관련 방
3. 대학 새내기방·동아리방 — 나이대가 맞습니다

**파티 홍보 전용 방은 효율이 나쁩니다.** 거기 있는 사람들은 대부분
홍보하러 온 사람이지 놀러 갈 사람이 아닙니다.

## 안 쓴 것

- **성비** — 당일 보장이 아니고, 오픈챗은 캡처가 제일 잘 돌아다닙니다
- **"마지막 기회"** — 3차가 남아 있는 동안은 거짓입니다
- **이모지** — 한두 개는 괜찮은데 줄마다 붙이면 업자로 보입니다
- **해시태그** — 카톡에서는 아무 기능도 안 하고 광고 티만 납니다
