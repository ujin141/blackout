# 오픈채팅방에 올릴 글

## 이걸 쓰세요

```
8/29(토) 양재 루프탑에서 풀파티 합니다.
9시 반부터는 솔로파티라 혼자 와도 돼요.

30자리 남았고 사전예약만 받습니다.
https://forms.gle/sue3a9jZNCi8U8dC7
```

**네 줄이 상한입니다.** 오픈챗은 스크롤로 넘기는 판이라, 길면 읽는 게
아니라 그냥 지나갑니다.

## 대화에 끼워 넣을 땐 두 줄

누가 "주말에 뭐 하지" 하면 답으로 답니다. **이게 제일 잘 먹힙니다** —
홍보가 아니라 대답이라 아무도 뭐라 안 합니다.

```
저희가 29일 토요일에 양재 루프탑에서 풀파티 해요. 혼자 와도 되게 솔로파티 시간 따로 있어요.
https://forms.gle/sue3a9jZNCi8U8dC7
```

## 뺀 것과 이유

주소 · 시간 · 라인업 · 애프터 · 정원 80명 · 3차 인상 — **전부 뺐습니다.**

**궁금하면 물어봅니다.** 오픈챗은 답장이 바로 오는 판이라, 다 적어 두는 것보다
**물어보게 만드는 게** 낫습니다. 질문이 붙으면 방 사람들이 그걸 같이 보고,
그게 글 하나 더 올리는 것보다 셉니다.

한 줄에 하나씩만 남겼습니다.

```
언제 어디   8/29(토) 양재 루프탑
왜 우리     혼자 와도 된다
왜 지금     사전예약만 받는다 (현장 판매 없음)
어떻게      링크
```

**값은 안 적습니다.** 사전예약제라 원래 판에 안 적기로 한 것이고,
물어보면 그때 답하면 됩니다 — 오픈챗은 답장이 바로 오는 판입니다.
