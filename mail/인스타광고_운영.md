# 인스타 광고 — 예약으로 이어지게 하는 순서

남은 자리 60명, D-13, 마케팅 예산 100만 원 기준입니다.

**제일 먼저 고쳐야 할 건 소재가 아니라 측정입니다.** 지금은 광고를 돌려도
누가 광고 보고 예약했는지 알 방법이 없습니다 — 그 상태로 100만 원을 쓰면
어느 소재가 먹혔는지 모른 채 끝납니다.

---

## 0. 오늘 안에 — 폼에 한 줄 추가

구글폼에는 **픽셀이 안 붙습니다.** 메타 광고 관리자에서 보이는 건
"링크 클릭"까지고, 그 뒤에 예약을 했는지는 전혀 안 잡힙니다.

**폼 맨 아래에 객관식 한 문항을 넣으세요.**

```
어디서 보고 오셨나요?
  ○ 인스타 광고
  ○ 인스타 게시물·릴스
  ○ 친구 소개
  ○ 크루 멤버
  ○ 기타
```

이 한 줄이 **광고비를 쓸지 말지를 정하는 유일한 근거**가 됩니다.
없으면 13일 뒤에 "광고가 됐나?" 에 아무도 답을 못 합니다.

**더 정확히 보려면** 광고용 링크를 사전 입력 링크로 따로 만드세요 —
구글폼 `응답 미리 채우기` 로 '인स타 광고' 가 선택된 링크를 뽑아
광고에만 그 링크를 씁니다. 사람이 안 골라도 자동으로 찍힙니다.

## 1. 목표를 '트래픽' 이 아니라 '참여' 나 'DM' 으로

전환 추적이 안 되므로 **'전환' 목표는 쓰지 마세요.** 메타가 최적화할
신호가 없어서 돈만 태웁니다.

| 목표 | 언제 |
|---|---|
| **참여(Engagement)** | 지금 단계. 릴스 조회·저장·공유를 모읍니다 |
| **트래픽** | 폼으로 바로 보낼 때. 클릭당 단가로 정산 |
| **DM(메시지)** | 테이블 문의를 받을 때. **문턱이 제일 낮습니다** |

**둘을 같이 돌리세요.** 참여로 도달을 넓히고, 그때 모인 사람에게
트래픽/DM 으로 다시 붙이는 게 이 규모에서 제일 쌉니다.

## 2. 타겟 만들기 — 그대로 넣으면 되는 값

### 광고 세트 A · 새 사람 (1~3일차는 이것 하나만)

```
위치      서울특별시
          + 양재역 반경 15km 를 따로 얹지 마세요.
            서울은 지하철로 다 옵니다 — 반경으로 좁히면 모수만 줍니다

나이      23 ~ 34
          미성년자 입장 불가라 아래를 잘라야 하고, 22 이하는 가격에서
          걸립니다. 위는 34 에서 끊습니다

성별      전체
          한쪽만 돌리면 성비가 한쪽으로 쏠립니다. 한 세트에서 둘 다 받고
          당일 성비는 예약 단계에서 조절하세요
```

**상세 타겟팅** — 아래를 검색해서 나오는 것을 **OR 로만** 넣습니다.

```
1순위 (이건 꼭)
  나이트클럽
  일렉트로닉 댄스 뮤직 (EDM)
  하우스 뮤직
  디스크자키 (DJ)

2순위 (모수가 너무 작으면 추가)
  음악 페스티벌
  클럽 음악
  테크노
  나이트라이프
```

**모수는 20만~50만이 맞습니다.** 흔히 "넓게 두고 메타에게 맡기라" 고 하는데
그건 하루 수십만 원을 쓸 때 얘기입니다. 하루 5만 원이면 노출이 하루
1만 건 안팎이라, 모수가 150만이면 **12일 동안 그 중 5% 만 스치고 끝납니다.**
같은 사람에게 두세 번 닿아야 기억에 남는데 그럴 기회가 아예 없습니다.

**'타겟 좁히기(AND)' 는 쓰지 마세요.** 서울 23~34 라는 지역·나이 조건이
이미 좁습니다. 여기서 AND 로 또 좁히면 모수가 몇만 명으로 떨어지고,
그러면 같은 사람에게 하루에 몇 번씩 나가서 노출 단가가 확 오릅니다.

**'상세 타겟팅 확장' 은 끕니다.** 예산이 작을 때 켜면 관심사 밖으로 새서
서울 밖·나이 밖 사람에게 나갑니다.

**'어드밴티지+ 잠재 고객' 도 끕니다.** 전환 신호가 없어서(구글폼) 메타가
학습할 게 없습니다 — 직접 만든 관심사 타겟이 낫습니다.

### 노출 위치 — 수동으로

자동에 두면 **오디언스 네트워크**(외부 앱)로 새서 잘못 누른 클릭이 섞입니다.
수동으로 바꾸고 아래만 켜세요.

```
켠다   인스타그램 릴스 · 인스타그램 스토리 · 인스타그램 피드
       인스타그램 탐색 탭
끈다   오디언스 네트워크 · 페이스북 전부 · 메신저
```

우리 소재가 전부 9:16 세로라 **릴스와 스토리가 본체**입니다.

### 광고 세트 B · 리타겟 (4일차부터 추가)

새 사람보다 **이미 우리를 스친 사람에게 파는 게 훨씬 쌉니다.**
맞춤 타겟에서 아래를 만들어 두세요 — 지금 만들어야 4일차에 모수가 찹니다.

```
1. 인스타그램 계정 · 지난 365일 참여한 모든 사람
2. 동영상 · 우리 릴스를 50% 이상 본 사람 (지난 90일)
3. 인스타그램 계정 · 프로필을 방문한 사람
```

**오늘 만들어 두세요.** 맞춤 타겟은 만든 시점부터 쌓이는 게 아니라
과거 데이터를 끌어오지만, 모수가 최소 규모를 넘어야 광고가 나갑니다 —
지금 만들어 두고 4일차에 쓰는 게 안전합니다.

## 3. 소재 — 첫 1초와 자막

- **소리 없이 봅니다.** 자막이 없으면 아무 말도 전달 안 됩니다
- **첫 1초에 사람이 나와야 합니다.** 로고·타이틀로 시작하면 넘어갑니다
- **9:16 · 15초 이하.** 지금 만든 릴스가 다 여기 맞습니다
- 화면 **아래 25% · 위 14%** 는 UI 가 덮습니다. 글자를 거기 두지 마세요

**돌릴 소재 세 개**를 정해 두고 같은 예산으로 붙여 봅니다.

| | 파일 | 훅 |
|---|---|---|
| **A** | **`short_ad.mp4`** | **혼자 와도 되는 풀파티** — 광고 전용 |
| B | `short_promo.mp4` | 입장 무료 + 샴페인 |
| C | `short_sale.mp4` | 20명은 이미 갔습니다 |

**A 를 기본으로 두세요.** 나머지 둘은 게시물용으로 만든 거라 값이 안 들어가
있습니다 — 광고는 처음 보는 사람에게 나가서, 값을 숨기면 "얼만데?" 에서
멈춥니다.

```bash
cd video && python short_card.py ad
```

A 안의 순서는 전환용으로 다시 짰습니다.

```
훅    혼자 와도 되는 풀파티        약속과 형식을 한 줄에
무엇   9시 반부터 솔로파티
문턱   아는 사람 없어도 됩니다      못 오던 이유를 지운다
증거   80명 중 20명은 갔습니다      남이 이미 샀다
값     여 49,000 · 남 59,000      못 낼 사람을 여기서 거른다
지금   3차부터 10,000원 오릅니다    ← 카드를 꺼내게 하는 건 이 한 줄이다
행동   프로필 링크에서 예약
```

**값과 인상 고지가 이 판의 심장입니다.** 앞의 다섯은 다른 판에도 있지만,
지금 사야 할 이유를 주는 건 "내일 사면 만 원 더" 하나뿐입니다.

**현장 컷도 광고용으로 따로 골랐습니다** — 손님 정면 얼굴이 가운데 오는
순간을 뺐습니다. 게시물은 팔로워가 보지만 광고는 모르는 사람 수만 명에게
나가고, 캡처가 남습니다.

**3일 돌리고 조회 단가·저장·공유가 제일 좋은 하나에 몰아주세요.**
셋을 끝까지 균등하게 돌리는 게 제일 흔한 낭비입니다.

## 4. 광고 문구 — 첫 두 줄이 전부

인스타가 두 줄 뒤를 접습니다. **접히기 전에 무엇을 주는지가 나와야** 합니다.

### A · 혜택형

```
입장 무료 + 샴페인 한 병, 3팀 드립니다.
8/29 토요일 양재 루프탑 풀파티.

정원 80명 중 1차 20명은 이미 마감됐습니다.
2차 예약은 프로필 링크에서.
```

### B · 사회적 증거형

```
광고 한 번 안 돌렸는데 1차 20명이 찼습니다.
남은 건 60자리입니다.

8/29 토요일 · 양재 어나더 루프탑 라운지
2차 입장 여 49,000 · 남 59,000 (3차부터 오릅니다)
```

### C · 문턱 낮추기형

```
혼자 가도 되는 파티를 만들었습니다.
9시 반부터 한 시간 반은 솔로파티입니다.

8/29 토요일 양재 루프탑. 정원 80명.
```

**CTA 버튼은 `지금 신청하기`** 로 둡니다. `더 알아보기` 는 클릭은 늘고
예약은 안 늡니다 — 알아보러 온 사람은 알아보고 나갑니다.

## 5. 하루 5만 원 — 몇 명이 나와야 남는가

**먼저 손익분기를 계산해 두세요.** 광고로 온 손님 한 명이 우리에게 남기는 값은
이렇습니다.

| | 우리 몫 |
|---|---|
| 입장비만 (평균 54,000 × 5:5) | **27,000원** |
| 락커·바 몫까지 더하면 | **38,000원** |

그래서 하루 5만 원이면 이렇게 갈립니다.

| 하루 예약 | 1인당 광고비 | |
|---|---|---|
| 1명 | 50,000원 | **손해** |
| **2명** | **25,000원** | **남는다** |
| 3명 | 17,000원 | 남는다 |

**하루 5만 원이면 최소 2명은 나와야 합니다.** 사흘 연속 하루 1명이면
소재나 타겟이 아니라 **광고 자체를 멈추는 게 맞습니다** — 그 돈을 협찬이나
커뮤니티로 돌리세요.

### 13일 × 5만 = 65만 원

| 하루 예약 | 13일 합계 | 남은 60자리 중 |
|---|---|---|
| 1명 | 13명 | 22% |
| 2명 | 26명 | 43% |
| 3명 | 39명 | 65% |

**광고만으로 60자리를 다 채울 수는 없습니다.** 하루 3명이 나와도 65% 입니다 —
나머지는 협찬·커뮤니티·입소문이 채워야 합니다. 광고에 100만 원을 다 밀어넣지
않는 이유가 이겁니다.

### 65만 원을 어떻게 나눌지

| 기간 | 하루 | 무엇 |
|---|---|---|
| **1~3일차** | 5만 | 광고 세트 **하나**에 소재 3개. **재는 기간** |
| **4~9일차** | 5만 | 새 타겟 3만 + 리타겟 2만으로 쪼갠다 |
| **10~13일차** | 5만 | 리타겟에 몰아주고 마감 압박 문구로 |

**소재마다 광고 세트를 따로 만들지 마세요.** 5만 원을 셋으로 쪼개면
하나당 1.7만 원인데, 그 돈으로는 메타가 학습을 못 끝냅니다 —
**세트는 하나로 두고 그 안에 소재 3개를 넣어** 메타가 돌리게 합니다.

**남는 35만 원은 예비로 두세요.** 6일차에 하루 2명 이상이 확인되면 그때
하루 예산을 7~8만 원으로 올리는 데 씁니다. 안 되면 안 씁니다.

## 6. 무엇을 보고 끄고 켤지

숫자는 돌려 봐야 나옵니다. **다만 판단 기준은 미리 정해 두세요** —
돌리면서 정하면 아까워서 못 끕니다.

- **3일차**: 소재별 클릭 단가를 비교해 **제일 나쁜 하나를 끕니다**
- **6일차**: 폼 응답의 '인스타 광고' 비율을 봅니다.
  광고비 ÷ 광고 유입 예약자 = **1인당 획득 비용**.
  이 값이 **입장료(49,000 ~ 59,000)를 넘으면 광고를 멈추고 협찬·커뮤니티로
  돌리세요.** 넘는 돈을 계속 쓰는 건 자리를 사는 게 아니라 손해를 사는 겁니다
- **10일차**: 남은 자리가 20 아래면 광고를 줄이고 가격 인상(3차)을
  알리는 쪽으로 바꿉니다

## 7. 광고로 하면 안 되는 것

- **성비 언급.** 지금 반반이어도 당일 보장이 아니고, 광고는 캡처가 남습니다
- **"마지막 기회".** 3차가 남아 있는 동안은 거짓입니다
- **얼굴이 크게 나오는 손님 컷.** 광고는 도달이 넓어서 초상권 문제가
  게시물보다 훨씬 큽니다. 지금 소재는 다 흐려 놨으니 그대로 쓰세요
- **노출 위주 이미지.** 인스타가 광고 심사에서 반려하거나 계정에 제한을
  겁니다. 60석 파는데 계정이 막히면 그게 제일 큰 손해입니다
