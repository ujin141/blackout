# 여성 크루원 모집 — 스토리

**한 장으로 끝내지 마세요.** 크루 모집은 "같이 하실 분" 한 줄로는 아무도 안 옵니다.
스토리는 넘기면서 보는 판이라 **넉 장으로 나눠서 한 장에 한 문장씩** 두는 게
제일 잘 읽힙니다.

---

## 핵심 — 우리가 남과 다른 지점

크루 모집 글은 서울에 널렸고 대부분 이렇게 씁니다.

> 같이 활동하실 분 구합니다. 관심 있으신 분 DM 주세요.

**우리는 보여줄 게 있습니다.** 8월 29일에 실제로 판을 엽니다.
말로 "우리 이런 크루예요" 하는 것보다 **"29일에 뭐 하는지 보고 판단하세요"**
가 훨씬 셉니다. 증거가 있는 쪽이 이깁니다.

그리고 이게 모집 글이면서 동시에 행사 홍보가 됩니다.

---

## 스토리 넉 장 — 이게 본편

각 장에 이 글자만 올리세요. 배경은 아래 [배경](#배경) 참고.

### 1장

```
BLACKOUT

여성 크루원 찾습니다
```

### 2장

```
DJ · 콘텐츠

경력 안 봅니다.
지금 시작해도 됩니다.

서울에서 활동 가능한 분
```

**무슨 자리를 뽑는지 2장에 적는 게 중요합니다.** '크루원' 만 적으면 뭘 하는
자린지 몰라서 DM 을 안 합니다. 자리를 적어야 "나 저거 되는데" 가 나옵니다.

### 3장

```
8월 29일 양재 루프탑에서
파티 합니다.

우리가 뭐 하는 크루인지
그거 보고 판단하세요.
```

### 4장

```
DM 주세요.
DJ 면 믹스 하나, 아니면 계정만.

@blackoutcrew_official
```

**4장에 답장 스티커를 붙이세요.** DM 을 새로 여는 것보다 스티커에 바로 치는 게
문턱이 훨씬 낮습니다. 지원이 몇 배 차이 납니다.

## 피드에도 올린다면

스토리는 24시간이면 사라집니다. **피드에 하나 남겨 두고 스토리에서 그걸
링크하는 게** 오래 갑니다.

```
여성 크루원 찾습니다.

서울에서 같이 활동할 사람입니다.
DJ 도 좋고 콘텐츠 쪽도 좋습니다. 경력은 안 봅니다.

8월 29일 양재 루프탑에서 파티 합니다.
풀파티고, 9시 반부터는 솔로파티로 돌립니다.
우리가 뭐 하는 크루인지는 그거 보고 판단하시면 됩니다.

지원은 DM.
DJ 면 믹스 하나, 아니면 계정만 주시면 됩니다.
```

**해시태그는 붙이더라도 다섯 개 안쪽으로.** 스무 개씩 달면 계정이 싸 보입니다.

```
#여성디제이 #DJ크루 #서울DJ #크루원모집
```

## 판

**한 장짜리가 기본입니다.**

```bash
cd video && python crew.py
```

`video/out/crew/crew.png` — 1080×1920.

한 장 안에 넷을 다 넣었습니다. **넷 중 하나라도 빠지면 DM 이 안 옵니다.**

| | |
|---|---|
| 무엇을 | 여성 크루원 |
| 어떤 자리 | DJ · 콘텐츠 |
| 문턱 | 경력 안 봅니다 |
| 어디로 | DM |

자리를 안 적으면 "나한테 하는 말인가" 에서 멈추고, 문턱을 안 낮추면
"나는 아직 아니지" 로 끝납니다.

### 넉 장짜리도 있습니다

```bash
cd video && python crew.py 4
```

`crew_1.png` ~ `crew_4.png`. **다만 지금은 한 장이 낫습니다** —
넉 장을 끝까지 넘겨 보는 건 이미 우리를 아는 사람이고, 모르는 사람은
첫 장에서 넘깁니다. 팔로워가 늘고 나서 쓰세요.

넉 장은 한 덩어리로 읽히게 셋을 묶었습니다.

- **빛이 왼쪽에서 오른쪽으로 흐릅니다** — 1장은 왼쪽, 4장은 오른쪽이 밝습니다
- 머리에 `BLACKOUT` 과 `01 / 04` 가 같은 자리에 앉습니다
- 글이 전부 같은 왼쪽 선에서 시작합니다

3장만 지난 행사 사진이 깔립니다. 앞뒤가 글자뿐이라 한 장은 숨이 트여야 하고,
"우리가 뭐 하는 크루인지" 는 말보다 사진이 빠릅니다. 브랜드 판이라 흑백으로
눌러서 넣었습니다.

**4장 아래 1267~1497px 는 비워 뒀습니다** — 거기에 답장 스티커를 올리세요.

### 문구를 바꿀 때

`video/crew.py` 맨 위 네 줄만 고치면 넉 장이 다 따라옵니다.

```python
WHO   = '여성 크루원'          # DJ 만 뽑을 거면 '여성 DJ'
ROLES = 'DJ  ·  콘텐츠'        # 무슨 자리를 뽑는지
WHERE = '서울에서 활동 가능한 분'
SEND  = ('DJ 면 믹스 하나,', '아니면 계정만.')
```

## 보내기 전에 정할 것

**아래를 안 정하고 올리면 DM 이 와도 답을 못 합니다.** 첫 DM 에 "그건 아직
안 정했어요" 라고 하면 거기서 끝납니다.

- **DJ 만 찾는 건지.** 콘텐츠·운영도 뽑을 거면 1장 문구를 `여성 크루원 찾습니다`
  로 바꾸고 2장에 무슨 자리인지 한 줄 넣으세요
- **경력 무관이 맞는지.** 위 문안은 무관으로 썼습니다. 실력을 볼 거면
  `믹스 하나만 보내주세요` 가 그 역할을 합니다 — 문구는 그대로 두고 심사에서 거르세요
- **대우.** 행사 출연료가 있는지, 수익을 나누는지, 아니면 지금은 무보수인지.
  **글에는 안 적었습니다** — 첫 스토리에 조건을 다 적으면 아무도 DM 을 안 합니다.
  다만 **DM 오면 바로 답할 수 있게 미리 정해 두세요**
- **몇 명 뽑는지.** 안 적는 게 낫습니다. 적어 두면 그 수를 못 채웠을 때 티가 납니다
- **프로필 링크.** 지금 예약 폼으로 걸려 있습니다. 모집 기간에도 그대로 두시고,
  지원은 DM 으로 받으세요 — 링크를 바꾸면 행사 예약이 끊깁니다

### 여성으로 한정하는 것에 대해

**크루 멤버 모집이면 문제 없습니다.** 다만 급여를 주고 사람을 쓰는 **채용**이면
남녀고용평등법상 성별 제한 모집이 걸립니다. 지금 문안은 크루 활동을 전제로
썼습니다. 돈을 주고 일을 시키는 형태면 문구를 바꿔야 하니 말씀 주세요.
