# 재무상태표 — 제1기

`재무상태표_제1기.txt` 는 **탭으로 나뉘어 있어서 엑셀에 그대로 붙여넣으면**
칸이 맞습니다.

---

## 무엇을 채웠나

**주신 숫자는 자본금 375 하나입니다.** 단위가 원이라 **3,750,000원**으로 적었습니다.
375,000,000원이면 뒤에 0 세 개를 더 붙이시면 됩니다 — 여섯 칸만 고치면 됩니다.

여기에 장비 네 건 **143,200원**을 뺐습니다.

```
자산   현금및현금성자산    3,606,800   (3,750,000 − 143,200)
부채   없음
자본   보통주자본금        3,750,000
       미처리결손금         (143,200)
       ───────────────────────────
       자본총계            3,606,800
```

자산총계 3,606,800 = 부채와자본총계 3,606,800. 대차가 맞습니다.

## 장비 네 건 — 자산이 아니라 비용으로 잡았습니다

| 품목 | 금액 |
|---|---|
| 버블 팝팝 기계 | 58,900 |
| 스모크 기계 | 36,400 |
| 스모크액 | 35,100 |
| 리필용 비눗방울액 | 12,800 |
| **합계** | **143,200** |

**기계 두 대를 비품(유형자산)으로 안 올린 이유가 있습니다.**
거래단위별 100만 원 이하인 소액 자산은 산 해에 전액 비용으로 털 수 있습니다.
5만 원짜리 기계를 자산으로 올려 두면 몇 년에 걸쳐 감가상각을 잡아야 하는데,
**세금에도 불리하고 장부만 복잡해집니다.**

액체 둘(스모크액·비눗방울액)은 쓰면 없어지는 거라 어차피 소모품비입니다.

### 우리 물건인데 왜 자산이 아닌가

**소유와 자산 계상은 다른 얘기입니다.** 기계는 우리 겁니다 — 팔든 부수든
마음대로 합니다. 그런데 장부에 자산으로 올릴지는 **금액으로 갈립니다.**

100만 원 이하 소액 자산까지 전부 자산으로 올리면 몇 년치 감가상각을
매년 따라다녀야 하는데, 5만 원짜리에 그걸 하는 데가 없습니다.
그래서 세법이 **바로 털 수 있게 열어 둔 겁니다.**

**굳이 자산으로 올리고 싶으시면** 이렇게 됩니다.

```
자산   현금및현금성자산    3,606,800
       비품                   95,300   (58,900 + 36,400)
       ───────────────────────────
       자산총계            3,702,100

자본   보통주자본금        3,750,000
       미처리결손금          (47,900)   (액체 둘만 비용)
       ───────────────────────────
       자본총계            3,702,100
```

**추천하지 않습니다.** 세금이 늘고(비용이 줄어서), 매년 감가상각을 잡아야 하고,
나중에 버릴 때 폐기 처리까지 해야 합니다. 얻는 게 없습니다.

**소모품비 대신 다른 이름을 쓰셔도 됩니다** — 행사 장비니까 `행사비` 나
`지급수수료` 로 묶는 곳도 있습니다. **세무사가 쓰는 계정 이름에 맞추세요.**
어떤 이름을 쓰든 금액과 대차는 그대로입니다.

**손익계산서에도 이 143,200이 잡혀야 합니다.** 재무상태표에는 결과(결손금)만
보이고, 비용 자체는 손익계산서에 있습니다. 두 장이 짝입니다.

### 챙길 것

- **증빙.** 세금계산서·현금영수증·카드전표 중 하나가 있어야 비용으로 인정됩니다.
  개인 카드로 사고 영수증만 있으면 인정이 까다로워집니다
- **법인 카드·법인 계좌로 결제한 게 맞는지.** 개인 돈으로 사셨으면 이 표에서
  빼야 하고, 대신 회사가 갚을 돈(미지급금)으로 잡거나 그냥 개인 부담으로 둡니다

## 지인 50만은 자본금인가, 빌린 돈인가

**이걸 먼저 정해야 표가 정해집니다.** 같은 50만 원이 어디에 앉느냐가 달라집니다.

### A · 주식을 발행해 준 경우 → 자본금

돈을 받고 **주식을 배정**했다면 자본금이 맞습니다. 지금 표 그대로입니다.

```
자본금        3,750,000   ← 총액은 그대로
  우진 외       3,250,000   (86.7%)
  지인            500,000   (13.3%)
```

**주주 구성은 재무상태표에 안 나옵니다.** 주주명부와 주석13에 적습니다.

확인할 것:
- **등기부등본의 자본금이 3,750,000인지.** 안 맞으면 증자 등기가 빠진 겁니다
- **액면가와 주식 수** — 액면 5,000원이면 총 750주 중 지인 100주,
  액면 100원이면 총 37,500주 중 지인 5,000주. 액면가를 모르면 주주명부를 못 씁니다

### B · 돈만 받은 경우 → 부채

**"나중에 원금 돌려주고 수익 나눠준다" 는 투자가 아니라 빌린 돈입니다.**
주식을 안 줬으면 자본금이 아닙니다. 그러면 표가 이렇게 바뀝니다.

```
부채   단기차입금(또는 주임종단기차입금)   500,000
자본   보통주자본금                      3,250,000
       ─────────────────────────────────────────
       부채와자본총계                    3,750,000
```

자산총계 3,750,000은 그대로고, 오른쪽에서 50만이 자본에서 부채로 내려갑니다.

### 황덕익 님 200만도 같은 문제입니다

제안서에 쓴 조건이 **원금 전액 반환 + 수익의 20%** 입니다. 이건 구조상
**주식이 아니라 빌린 돈**입니다 — 주식이면 원금 보장을 못 합니다.

**그 200만이 법인으로 들어오면 자본금이 아니라 부채로 잡힙니다.**
개인 대 개인으로 하신 거면 법인 재무제표와는 무관합니다. 이것도 구분하세요.

## 그대로 쓰면 안 되는 경우

**회사 이름으로 돈이 한 번이라도 오갔으면 이 표는 틀립니다.**

- 매출이 있었다 → 이익잉여금과 자산이 바뀝니다
- 회사 카드·계좌로 뭘 샀다 → 현금이 줄고 비용이 잡힙니다
- 설립비용(등록면허세·법무사비)을 회사 돈으로 냈다 → 현금이 그만큼 줍니다
- 사무실 보증금을 걸었다 → 임차보증금으로 넘어갑니다
- 통장에 자본금이 안 들어와 있다 → 주임종단기대여금이나 가지급금으로 잡힙니다

**8/29 행사 관련 지출(대관 125 · 샴페인 200 · 마케팅 100 · 운영 100)이
법인 명의로 나간 것이라면 이 표에 반영돼야 합니다.** 개인 돈으로 하신 거면
법인 재무제표와는 무관합니다 — 이 구분부터 확실히 하셔야 합니다.
